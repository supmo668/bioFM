## Pipeline that will produce the results

```bash
cd projects/perturb-seq-eval

# 1. The sweep: preflight + trainer sweep + lifecycle sweep in one process.
#    ANTHROPIC_API_KEY is injected by Infisical (never written to disk) and
#    LLM_KEY_SOURCE records its source; preflight refuses the whole run
#    without either, and requires paper/PREREGISTRATION.md committed with no
#    local edits (the pinned pre-registration).
LLM_KEY_SOURCE=infisical:syntropyhealth-app:dev infisical run \
    --projectId 589d1e3b-5798-48ea-97c0-2d58086a375b --env dev -- \
    modal run scripts/modal/app_v05.py::entrypoint --version v0.6.0 \
    --norman-n-singletons 15 --norman-n-doublets 5 --seeds 3 --prior-spend-usd 1.3548

# 2. Analyse the downloaded run files -> artifacts/v0.6.0/summary.json
python -m perturb_eval.experiments.e_v05_real_traces artifacts/v0.6.0
```

`scripts/paper/fill_v060_numbers.py` writes `sections/generated_numbers.tex` from
`summary.json`, `provenance.json`, `lifecycle_runs.jsonl` and
`data/projection_v060.json`; `--check` fails if the committed file is stale
(`tests/test_fill_v060_numbers.py`). `scripts/paper/fill_v050_numbers.py` fills
`sections/v050_results.tex`, which `paper.tex` no longer inputs. Build products
(`paper.pdf`, `.aux`, `.log`, `.out`, `.bbl`, `.blg`) are not tracked; rebuild with
`latexmk` from the sources.
