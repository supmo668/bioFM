# §vision — bioFM

What is being attempted and why now. Source is the principal's request; the PVR is the Wiki rendering.

## Workstreams

- **lung-on-chipsim** — a PoC in-silico lung-on-a-chip: predict on-chip drug transport and barrier
  response, with every scientific input human-entered and cited.
- **perturb-seq-eval** — does agent confidence entropy predict task difficulty? A pre-registered
  test of agentic hyperparameter tuning on Perturb-seq response prediction.
- **aviary-biosim** — the v2r loop (vision → research → spec expansion → tracing) as a closed lab
  method, in a separate public repo.

## Standing constraint that shapes all three

No coding agent writes a biological number. The agent writes the schema and the validator that
rejects an unsourced entry; the human writes the value with its citation.
