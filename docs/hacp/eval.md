# §eval — bioFM

What proves it works — gates, receipts, sealed suites, run records.

## Pre-registration

**perturb-seq-eval** locks its hypotheses *and its estimator code* before the data exists, with the
pre-registration commit recorded in the run's own provenance so a referee can check the ordering
rather than trust it. Its gate reports every test regardless of outcome, so a pass driven by one
test is visible from the table.

## What evaluation does not yet exist

**lung-on-chipsim** has no results. Its evaluator is not yet frozen and its priors are not yet
entered. That is a blocked input, not a pending task.
